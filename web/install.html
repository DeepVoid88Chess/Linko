Linko
by Donaro Inc.

Install Linko for Windows

Linko lets you securely control your own Windows PC from your iPad or another device.

Download Linko.exe
Quick start
1. Download and run Linko.exe.
2. Enter your Linko server address.
3. Linko shows a six-digit pairing code.
4. Open Linko on your iPad and enter the code.
5. Confirm remote control locally on the Windows PC.

The download becomes available after the first Linko version is published on GitHub.
